# Snake Guide World

A responsive, no-build educational snake directory with search, regional and venom-category filters, saved species, a theme toggle, and a country/region emergency-number selector. It runs as a static site and does not use a paid API or collect account data.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required. GitHub Pages can host the static site for free.

## Features

- 34 starter species entries across Africa, Asia, Australia & Oceania, Europe, North America, and South America.
- Search across common names, scientific names, broad range, and habitat.
- Filter by region and broad venom category.
- Save species locally in the browser and switch between light and dark themes.
- Country/region emergency-number selector for India, the United States, Canada, the United Kingdom, Australia, New Zealand, and most EU member states.
- Mobile-friendly layout and basic accessibility support.

## Safety and data limitations

This is educational content, not a medical resource or a definitive identification tool. Geographic ranges and venom categories are simplified summaries; species status and accepted taxonomy can vary between references. Never use this guide to decide whether a snake is safe, and never handle a wild snake. For a suspected bite, contact local emergency services and seek urgent medical care.

Emergency-number coverage is intentionally limited. Numbers and availability can vary by locality, telecom network, and country. Confirm the correct number with official local sources, especially before travelling. The interface advises users to verify locally.

Before publishing or selling, have a qualified herpetologist review the species data and have local emergency numbers checked against current official government sources. Add clear image licenses/attributions if you later add photographs. Do not claim that a sale or a particular sale price is guaranteed.

## Emergency-number references

- India: [Emergency Response Support System (112 India)](https://112.gov.in/)
- United States: [911.gov](https://www.911.gov/)
- United Kingdom: [GOV.UK — 999 and 112](https://www.gov.uk/guidance/999-and-112-the-uks-national-emergency-numbers)
- Australia: [Triple Zero (000)](https://www.triplezero.gov.au/)
- European Union: [European Commission — 112](https://digital-strategy.ec.europa.eu/en/policies/112)
- Canada and New Zealand numbers are shown as general national numbers; confirm any local exceptions with the relevant local authority.

## Project status

A starter product, not a verified worldwide species database. The data and visual identity should receive expert and legal review before commercial use. No custom domain is required to run it locally or deploy it to a free static hosting URL.
