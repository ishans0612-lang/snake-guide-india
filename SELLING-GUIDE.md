# Sale package and listing draft

## Project
**Snake Guide World — Global wildlife guide starter project**

A static HTML/CSS/JavaScript educational website with a curated snake directory, search and filters, a separate catalog page that requests up to 2,000 taxonomy records from iNaturalist, a photo-suggestion page using iNaturalist computer vision, and Wikimedia Commons image lookup where available. No custom domain, user base, or revenue is included or claimed.

## What the buyer receives

- The project source files in this repository branch: `index.html`, `catalog.html`, `identify.html`, and `README.md`.
- Static website code and the right to continue developing it, subject to third-party service terms and the seller's rights in original code/content.
- Setup instructions for local/static hosting.

## Not included / important exclusions

- No custom domain, hosting account, registered business, user accounts, mailing list, revenue, or traffic history.
- No ownership of iNaturalist, Wikimedia Commons, their APIs, or third-party photos. API access and images remain subject to their own terms, limits, and individual image licenses. Buyers must preserve required image attribution.
- The website is an educational starter project, not a medically validated snake-identification service. Computer-vision suggestions are non-definitive and may be incorrect.
- No guarantee that external endpoints, data, or photo matches will remain available, or that a sale or revenue will result.

## Before listing or transferring

1. Test all three pages on mobile and desktop through HTTPS; confirm external API calls, camera/file picker behavior, and error states.
2. Verify the computer-vision endpoint response format, browser CORS behavior, rate limits, and current API terms with real test images. Do not promise this feature works until verified.
3. Check all taxonomy, species notes, and country emergency numbers against current authoritative sources; get expert review for wildlife and emergency content.
4. Check every photo's own license and attribution requirements. Do not treat all Commons images as having the same license.
5. Deploy a demo and include the actual live URL only after it works. Be transparent that no domain, users, traffic, or income are included if none exist.
6. Agree in writing what is transferred. Never hand over personal passwords or sell a personal GitHub account. Transfer repository ownership only through GitHub's official repository-transfer flow if that is part of the deal.
7. Check the marketplace's current listing rules, fees, payment and transfer process before accepting an offer.

## Paste-ready listing description

### Title
Snake Guide World — Static wildlife guide with global taxonomy catalog and photo-suggestion prototype

### Description
Snake Guide World is a responsive, no-build HTML/CSS/JavaScript educational website starter project. It includes a curated directory, search and filters, a separate catalog page designed to request up to 2,000 snake taxonomy records from iNaturalist, Wikimedia Commons photo lookup, and a camera/file photo-suggestion prototype that calls iNaturalist computer vision.

Included: source files, README/setup notes, and the repository branch. It can be hosted as a static site. No paid API is required, but external data/photo/suggestion features require internet access and depend on third-party services.

This is an early-stage code/project sale, not an operating business: no custom domain, revenue, users, or verified traffic are included. The photo suggestions are experimental and are not reliable identification or medical advice. Third-party APIs and images are not owned by the seller and remain subject to their respective terms and licenses. Buyer should independently test the APIs, review licenses, and obtain expert review of wildlife and emergency information before public or commercial use.
